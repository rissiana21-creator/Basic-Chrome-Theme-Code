# Google Chrome Theme

A custom, lightweight theme for Google Chrome. 

## 🛠️ How to Customize
Feel free to make this theme your own! You can easily swap out the design assets:
* **Manifest:** Update the `manifest.json` file to change your theme's name, version, or color configurations.
* **Images:** You can replace the background or header images, just make sure any new image files are saved in **PNG** format.
